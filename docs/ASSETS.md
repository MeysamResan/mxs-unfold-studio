# Asset provenance and preparation

## Lightning

- Artwork: **Lightning Pump Action Rifle**
- Creator: **LonesomeDucky**
- Source: https://opengameart.org/content/lightning-pump-action-rifle
- Source archive: https://opengameart.org/sites/default/files/lightning_pump_action_0.zip
- License: **CC0**, stated on the author's source listing
- Retrieved: 2026-09-06
- Original GLB size: 7,710,328 bytes
- Original visual mesh: 3,046 triangles in the downloaded GLB

The original archive includes a Blender source file and a GLB with textures and basic skinning. The source archive and authoring files are kept in ignored local cache, not silently committed into the repository.

The included release GLB is generated by `scripts/build-showcase.mjs`. Preparation preserves the artwork and the artist's Pump clip, adds six broad visual groups for inspection, resizes textures to 1024px WebP, removes unused data, and applies Meshopt compression. Groups are arranged for visual exploration; they are not engineering parts or an assembly/disassembly sequence. No manufacturing geometry or dimensions are supplied.

The generated output is content-hashed. `src/content/asset-manifest.json` records its exact URL and byte size. Do not rename or overwrite a released immutable asset with different bytes. Old exports should remain available when an already-published application still references them.

## Reproduce locally

1. Obtain the archive above and extract `lightning.glb` into `.cache/asset-sources/lightning/`.
2. Run `npm run assets:build` (or `node scripts/build-showcase.mjs <path-to-source.glb>`).
3. Inspect the result, then run the validation and browser checks.

Asset preparation is local. This script does not upload, deploy, initialize Git, or commit anything. It is intentionally specific to this source artwork. Build a separate importer for the next source; keep the runtime viewer generic.

## Future assets

Require source/credit information, meaningful node names, appropriate texture resolution, supported animations, and compatible redistribution terms. Keep source masters separate from delivery exports. A GLB with only exterior geometry cannot support a meaningful internal view.

For larger assets, evaluate quality tiers and KTX2/Basis GPU texture compression. The current decoder supports Meshopt; add and test any new decoder as a renderer adapter before declaring a corresponding content variant.

## Collection thumbnails

The Lightning preview at `public/media/thumbnails/lightning-f78c68582d73.webp` is a locally rendered still of the included CC0 GLB. It shows the assembled artwork with its original materials against a charcoal background. The image is 960 × 540 pixels and 8,850 bytes. This derivative retains the source artwork's **CC0** license; it is excluded from the software license and from the terms for original project-owned assets.

Thumbnail references belong to each showcase's `thumbnail` content record, with a content-hashed `/media/thumbnails/` path, descriptive alternative text, and fixed image dimensions. The collection renders ordinary lazy-loaded WebP images, not additional 3D canvases. A missing or unavailable preview receives a stable placeholder. A configured public asset origin serves these paths in the same way as model files.

For a new object, render a separate still of its approved source artwork, fit the whole silhouette within a 16:9 frame, and compress it as WebP. Keep the source asset's attribution and license with the resulting image. Do not apply the project-owned asset terms to a third-party derivative.
